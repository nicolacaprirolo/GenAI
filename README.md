# Gen AI — Homework 1: Coding Assistant Onboarding

This repository contains my Homework 1 submission for the Generative AI course (BU.330.760, Johns Hopkins Carey Business School, Spring 2026). It shows the workflow of using a coding assistant to draft a short Markdown file, editing it manually, and tracking the work in Git.

## Files

- `assistant_draft.md` — initial draft generated by Claude Code from a single prompt, with notes on the prompt and what the assistant did well or needed adjustment
- `final_version.md` — my manually edited version, with notes on what I changed, why, and one thing the assistant wrote that I did not want to keep as-is

## Git workflow

The steps I used:

1. Created a new repository on GitHub (`nicolacaprirolo/GenAI`) and connected it to a local project folder
2. Created `assistant_draft.md` and `final_version.md` for the initial setup
3. Used Claude Code to generate the content of `assistant_draft.md` from a single prompt, then committed
4. Copied the draft into `final_version.md` as a starting point and committed that as a separate commit
5. Edited `final_version.md` manually in my editor, without the assistant, and committed those changes
6. Added this `README.md` with the repo description and commit summary, then pushed everything to GitHub
