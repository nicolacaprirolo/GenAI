# HW1: Coding Assistant Onboarding

Onboarding exercise for the workflow used throughout the course: installing a coding assistant, setting up a GitHub repository, using the assistant to create and edit a small file, making a manual edit, and committing work along the way.

## What this homework demonstrates

- A coding assistant (Claude Code) is installed and working
- The assistant was used to create a file inside a project folder
- The assistant's draft was edited manually rather than accepted unchanged
- Basic Git workflow with commits at each step
- A short walkthrough video that documents the workflow

## Files

```
hw1/
├── README.md             # this file
├── assistant_draft.md    # initial draft generated by Claude Code from a single prompt
└── final_version.md      # my manually edited version, with notes on what I changed and why
```

- `assistant_draft.md` — initial draft generated by Claude Code from a single prompt, with notes on the prompt and what the assistant did well or needed adjustment
- `final_version.md` — my manually edited version, with notes on what I changed, why, and one thing the assistant wrote that I did not want to keep as-is

## Topic

The draft and final versions cover generative AI in frontline healthcare — specifically, how summarization, guideline-aware recommendations, and clinical documentation support could reduce the cognitive burden carried by clinicians in resource-constrained public health systems in Latin America. This is the same problem space I work on at Holi Labs.

## Manual edits applied to `final_version.md`

- **Clarity**: rewrote the opening of the problem-area paragraph to include the reality that patients often arrive "too late" to be properly treated, anchoring the abstract idea of cognitive burden in a concrete consequence
- **Personal thesis added**: a paragraph describing my view that generative AI can be used to *prevent* illness through multi-disciplinary protocols at the top of the funnel, not just react to it
- **One thing not kept as-is**: the assistant's original "not data storage or retrieval — it is contextualization and presentation at the right moment" framing was dropped because it felt academic and missed pattern detection, which is central to where AI adds value

## Git workflow

1. Created a new repository on GitHub (`nicolacaprirolo/GenAI`) and connected it to a local project folder
2. Created `assistant_draft.md` and `final_version.md` for the initial setup
3. Used Claude Code to generate the content of `assistant_draft.md` from a single prompt, then committed
4. Copied the draft into `final_version.md` as a starting point and committed that as a separate commit
5. Edited `final_version.md` manually in my editor, without the assistant, and committed those changes
6. Added the top-level `README.md`, then later moved the HW1 deliverables into this `hw1/` subfolder to match the structure used for HW2/HW3/HW4
7. Pushed everything to GitHub
