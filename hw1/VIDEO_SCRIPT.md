## Script

> Hi, I'm Nico Caprirolo. I'm an MBA student at Johns Hopkins Carey, and I'm also the founder and CEO of Holi Labs. This is my Homework 1 walkthrough for the Generative AI class.
>
> The coding assistant I used is Claude Code — you can see it open here on the right. My project lives at `github.com/nicolacaprirolo/GenAI`.
>
> *[Show `assistant_draft.md`]* This is the draft file Claude Code generated. The prompt I used is at the bottom — I asked it to write a short intro about me, a paragraph on a problem area I care about, and three ways generative AI could help. The topic is clinical decision support for frontline clinicians in Latin America, which is what we work on at Holi Labs.
>
> *[Show `final_version.md`]* This is the same file after I edited it manually, without the assistant. The main thing I changed was the framing of the problem. Claude's original version described the bottleneck as "contextualization and presentation at the right moment." I rewrote it to include pattern detection, and I added a paragraph about my actual thesis — that we can use generative AI to prevent illness, not just react to it.
>
> *[Switch to GitHub]* On GitHub, you can see the README, all three files, and the commit history showing the assistant draft, my edited version, and the setup commits.
>
> What I found surprising is how much of the assistant's first pass was already structurally correct — but how much the voice still felt generic until I rewrote it in my own framing. The cognitive work was less about facts and more about making it sound like me. Thanks.
